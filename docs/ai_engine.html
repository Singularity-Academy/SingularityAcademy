AI Engine API Documentation

Overview

The AI Engine provides a comprehensive set of APIs for frontend applications to interact with AI functionalities, including course management, AI chat, and real-time streaming capabilities. This documentation is intended for frontend developers who need to integrate with the AI Engine.

Note: All AI Engine routes are under specific prefixes (/course, /principal-ai, /dean) due to the application running behind a Caddy proxy.

Authentication

Most endpoints require authentication using JWT tokens. The token should be included in the request headers or as specified in individual endpoint documentation.

HTTP Request Authentication

Course Management API

All course management endpoints are available under the /course prefix.

POST /course/

Create a new course.

Authentication required: Yes

Request Body:

{
    "name": "Introduction to Deep Learning",
    "description": "Explore the fundamentals of neural networks and deep learning"
}

Response:

{
    "id": "uuid-string",
    "name": "Introduction to Deep Learning",
    "description": "Explore the fundamentals of neural networks and deep learning",
    "created_at": "2024-03-15T10:45:00Z",
    "updated_at": "2024-03-15T10:45:00Z",
    "outline": "Generating..."
}

GET /course/

List all courses with optional filtering.

Authentication required: Yes

Query Parameters:

  • owner_id - Filter by owner ID
  • search - Search in name and description
  • limit - Maximum number of courses (default: 50, max: 100)
  • offset - Number of courses to skip (default: 0)

Response:

{
    "courses": [
        {
            "id": "uuid-string",
            "name": "Course Name",
            "description": "Course Description",
            "created_at": "2024-03-15T10:45:00Z",
            "updated_at": "2024-03-15T10:45:00Z",
            "outline": "Course outline or 'Generating...'",
            "owner": {
                "id": 123,
                "username": "username"
            }
        }
    ],
    "total": 100,
    "limit": 50,
    "offset": 0
}

GET /course/{course_id}

Get a specific course by ID.

Authentication required: Yes

Response:

{
    "id": "uuid-string",
    "name": "Course Name",
    "description": "Course Description",
    "created_at": "2024-03-15T10:45:00Z",
    "updated_at": "2024-03-15T10:45:00Z",
    "outline": "Course outline or 'Generating...'",
    "owner": {
        "id": 123,
        "username": "username"
    }
}

PUT /course/{course_id}

Update a specific course.

Authentication required: Yes

Request Body:

{
    "name": "Updated Course Title",
    "description": "Updated course description"
}

DELETE /course/{course_id}

Delete a specific course.

Authentication required: Yes

POST /course/{course_id}/regenerate-outline

Manually trigger regeneration of a course outline.

Authentication required: Yes

Principal AI WebSocket API

All Principal AI endpoints are available under the /principal-ai prefix.

WebSocket /principal-ai/ws/chat

WebSocket endpoint for streaming chat responses from the Principal AI.

Authentication required: Yes (via initial message)

Connection Flow

  1. Establish WebSocket connection
  2. Send authentication message
  3. Receive authentication response
  4. Receive chat history (if available)
  5. Send and receive messages

Authentication Message

{
    "token": "your_jwt_token"
}

Authentication Response (Success)

{
    "type": "auth_success",
    "message": "Authentication successful",
    "user_id": "user_id_value"
}

Chat History Message

{
    "type": "history_messages",
    "messages": [
        {
            "role": "user",
            "content": "User message content",
            "timestamp": "2024-03-15T10:45:00Z"
        },
        {
            "role": "assistant",
            "content": "Assistant response content",
            "timestamp": "2024-03-15T10:46:00Z"
        }
    ]
}

Sending Messages

{
    "type": "message",
    "content": "Your message here"
}

Course Request Message

{
    "type": "course",
    "content": {
        "type": "create|update|delete",
        "name": "Course Name",           // Required for create
        "description": "Course Description", // Required for create
        "course_id": "uuid-string"       // Required for update/delete
    }
}

Response Types:

  • create_course - Sent when course is created (before outline generation)
  • course_outline - Sent when course outline is generated
  • update_course - Sent when course is updated
  • delete_course - Sent when course is deleted

Response Format:

{
    "type": "create_course|course_outline|update_course|delete_course",
    "course_id": "uuid-string",          // Not present for delete_course
    "name": "Course Name",               // Not present for delete_course
    "description": "Course Description", // Not present for delete_course
    "outline": "Course outline or 'Generating...'" // Only for create_course and course_outline
}

Dean WebSocket API Not Finished

All Dean endpoints are available under the /dean prefix.

WebSocket /dean/ws/{course_id}

WebSocket endpoint for handling real-time video and audio streams for course sessions.

Authentication required: Yes (via initial message)

Streaming Messages

{
    "video": "base64_encoded_video_frame",
    "audio": "base64_encoded_audio_frame"
}

Both video and audio fields are optional. At least one must be present in each message.

Error Codes

Error Code Description
AUTH_REQUIRED Authentication token is required
INVALID_TOKEN Invalid or expired token
INVALID_TOKEN_CLAIMS Invalid token claims
USER_NOT_FOUND User not found in database
COURSE_NOT_FOUND Course not found
PERMISSION_DENIED User doesn't have permission for the operation
